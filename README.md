# Tech Careers Intelligence Dashboard

An interactive Streamlit dashboard that explores hiring demand, salary trends, skills, industries, companies, and benefits across the tech job market.

## Overview

This project transforms raw job market datasets into an engaging interactive dashboard experience. It helps users explore tech job trends through filters, charts, KPI cards, and a searchable jobs table.

## Features

- Interactive dashboard for exploring tech hiring trends
- Salary insights by job title and industry
- Skills demand analysis
- Industry breakdowns
- Company hiring activity
- Benefits overview
- Remote job filtering
- Searchable and sortable job listings table
- Premium animated UI built with Streamlit

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## Datasets Used

This dashboard uses multiple job market datasets, including:

- Job postings
- Salaries
- Skills
- Industries
- Companies
- Benefits
- Employee counts
